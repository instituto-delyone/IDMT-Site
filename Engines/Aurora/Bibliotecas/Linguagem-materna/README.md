# Linguagem materna

Esta é a primeira biblioteca de linguagem do AIGAR.

Ela não é uma biblioteca temática como Medicina ou Fisiologia.

Ela orienta:

- intenção da pergunta;
- profundidade da resposta;
- ambiguidade;
- incerteza;
- comunicação básica;
- como decidir antes de buscar.

