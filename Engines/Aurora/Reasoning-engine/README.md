# Reasoning Engine — v0.1

Camada de raciocínio local do AIGAR.

## Função

Antes de responder, o sistema precisa formular uma pergunta latente:

```txt
input bruto
→ significado provável
→ pergunta real por trás do input
→ critério mínimo de compreensão
→ resposta contextual ou recusa por insuficiência
```
